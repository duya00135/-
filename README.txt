夏日潮汐集市当日利润计算（Windows exe）
==============================================

【双击启动】
夏日潮汐集市当日利润计算.exe

【使用说明】
1. 打开软件后，找到右上角附近的「📋 截图识别 · 最低价/最高价/价差」窗口。
2. 在该窗口里粘贴 1~3 张游戏截图：
   - 方法一（推荐）：截图后按 Ctrl+V，图片会自动填入「截图一/截图二/截图三」槽位。
   - 方法二：点击「📥 读取剪贴板」按钮，从剪贴板直接读取图片。
   - 方法三：把图片拖到槽位里。
   - 方法四：点击槽位，选择图片文件。
3. 多张截图可覆盖全部 15 种商品（每张图包含其中若干种，重叠部分会合并）。
4. 点击「🚀 开始识别」按钮，程序会逐张识别并按商品名合并结果。
5. 结果表格会显示每种商品的最低价、最高价、价差；套利空间最大的商品会高亮置顶。

【小技巧】
- 如果 Ctrl+V 没有反应，请使用「📥 读取剪贴板」按钮（WebView2 对页面 paste 事件支持不稳定，走 Python 直接读剪贴板最稳）。
- 软件首次识别时会加载 OCR 模型，大约需要 3~8 秒，请耐心等待。
- 识别结果只代表截图中可见的商品；未命中的商品请换一张包含该商品的截图补齐。

【命令行诊断】
夏日潮汐集市当日利润计算.exe --selfcheck
输出 JSON 表示打包资源与识别管线正常。

【注意】
- 本软件识别固定贴图的 15 种商品：迪莫/火花/喵喵/水蓝蓝/果冻/大耳帽兜/小黑猫/机械方方/护主犬/厉毒小萝/小翼龙/奔波鼠/甜筒脆脆/火尾瓦特/小独角兽物资包。
- 部分商品贴图已根据游戏真实截图校准（小独角兽 ref_15.jpg 来自截图裁切），以保证当前游戏版本下的识别准确率。
- 杀毒软件若误报 PyInstaller 打包的 exe，请将其加入信任。
